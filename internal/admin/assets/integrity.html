The store

Every object is named by the hash of its own bytes, so verifying the store is re-hashing all of it and checking that each object is still what its name says.

{{if .CanRun}}

Not run on page load. This reads and re-hashes the whole store, and doing that every time somebody opens a dashboard is how a check ends up switched off.

{{end}}

Encryption at rest

{{if .Encrypted}}

Objects are sealed. The active key is {{.ActiveKey}}, and the keyring holds {{len .Keys}}.

Old keys are kept so objects sealed under them stay readable. Rotation adds a key and changes which one new objects use; it does not rewrite what is already stored, because rewriting an immutable store is a contradiction.

{{else}}

Objects are stored unencrypted. That is the default, and it is the right default when the filesystem is already the trust boundary — encryption at rest protects against a stolen disk, not against a process that can read the directory.

{{end}}
