Build a whole site

As #rrggbb. Left empty, the kind of site picks one; every palette is checked for contrast.

You get pages, menus, a contact form, a privacy page written from what the forms collect, a question box that answers from the site's own pages, and a look. Nothing is made up: a price, an address or opening hours the description does not give is left as a blank for you to fill in. You read all of it before anything is installed. Without a model, the site needs a name.

Describe a feature

A model drafts types, records, listings, forms, pages, menus and chatbots, and nothing that reaches another server. You read the draft before anything is installed.

From a spreadsheet

Each column's kind comes from its values. Its rows are imported with the feature, once it is approved; the package itself carries no data.

Add a feature

Checking installs nothing. A complete example to start from: quilzo feature example > lab.json. Pages a feature adds go to the draft, so publishing them stays the usual review.
