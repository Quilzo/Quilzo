Three ways in, and they agree

Everything here is reachable from the browser, from the command line, and from the agent interface. A test walks the source and fails when a capability exists in one and not the others, because that gap is this project's most frequent bug rather than a hypothetical.

The same store, three surfaces
SurfaceForStart with
This interface Writing and reviewing, and everything administrative The menu on the left
The command line Scripting, pipelines and anything repeatable quilzo help
The agent interface Models that read and author content, and nothing else quilzo mcp --list

An agent can read and author. It deliberately cannot change who may do what, what code runs, or what the keys are — a prompt injection in a page an agent is reading is a plausible route to whatever that agent can call.
