Layouts

A page renders through the layout it names in its own layout field. A page that names none renders through page. A page naming a layout that is not here does not publish — it would render as nothing for a reader, so it is refused rather than quietly sent through the default.

Typefaces

{{if .Fonts}}

Served from this origin: {{range .Fonts}}{{.}} {{end}}

{{else}}

No typefaces of your own. Put a .woff2 in {{.Dir}}/fonts/ and it is served from this origin at /fonts/NAME.woff2, then set font-display to its name. The filename carries the family, the weight and the style: Satoshi-600.woff2, Satoshi-400..700.woff2, Satoshi-italic.woff2.

There is deliberately no way to name a font on somebody else's server. A page that fetches one has handed that server a request on every visit and the ability to stall the render, and the policy cannot help because the page asked for it.
