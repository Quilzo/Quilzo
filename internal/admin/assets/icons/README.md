# Navigation icons

These are [Material Symbols](https://github.com/google/material-design-icons)
(Rounded, weight 400, unfilled, 24px) by Google, licensed under the
Apache License 2.0, whose text is in `LICENSE` beside this file.

Each file is named after the screen it stands for, as keyed in
`internal/admin/nav.go`; the symbol's own name is in `icons.go`. They are
used unmodified, and only their single `path` is read.
