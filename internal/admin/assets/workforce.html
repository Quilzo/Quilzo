How a score is made

Every point is a fact a tool reported, with the tool's name on it. The worst machine a person uses counts, because an attacker needs one. An area no tool reports on scores nothing and is listed as unknown, never as safe. A tool's own score, such as KnowBe4's, is shown beside this one and never mixed into it.
