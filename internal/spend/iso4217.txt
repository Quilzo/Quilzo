# The currencies a mandate, a price or a payment may be in: ISO 4217 list
# one, the currencies and funds in use, each with the minor units ISO gives
# it. One a line: the code, how many places its amounts have, its name.
#
# Kept as data, beside the code that reads it, so that a change to the list
# (XCG for ANG in 2025, ZWG for ZWL in 2024, HRK withdrawn in 2023) is one
# line somebody can check against the published list, not a pattern nobody
# can.
#
# Left out on purpose: the codes ISO lists with no minor unit. Gold, silver,
# platinum and palladium (XAU, XAG, XPT, XPD), the SDR (XDR), the European
# bond market units (XBA to XBD), the Sucre (XSU), the ADB unit (XUA), the
# testing code (XTS) and "no currency" (XXX) have no smaller unit to count
# an amount in, so a budget in one of them cannot be checked.
#
# Crypto assets are not here and are never added: a token's decimals are
# whatever its contract says, not a fact ISO fixes, and Quilzo holds no
# wallet and signs no transaction (internal/admin/decentralised.go).
